# Plan 17 — Post-2.1.0 code fixes

**Date:** 2026-10-07
**Linear:** [NIW2-8](https://linear.app/niway/issue/NIW2-8) — code part only
**Stacked on:** [Plan 16](/plans/2026-10-07-16-docs-housekeeping/)

Three defects found in the 2.1.0 release review. The ticket's release chores
(release notes on the GitHub release, marking v2.1.0 "Latest", merging #66) are
Cristian's and are not part of this plan.

## Tasks

- [ ] **`laqi mcp` reports the real version.** `serverInfo.version` is the
      literal `"2.0.0"` in `packages/mcp/src/server.ts`. `createMcpServer` and
      `startMcpStdio` take the version from the caller; the CLI passes
      `laqiVersion()`, which is the published `laqi` package version (build-time
      define, or `apps/cli/package.json` from source). `@laqi/mcp`'s own
      `package.json` version is private and not release-managed, so it is not
      the number to report. Test: over real stdio, `getServerVersion().version`
      equals `apps/cli/package.json`'s version.
- [ ] **`int64` stays inside the safe-integer range.** `NUMERIC_FORMATS.int64`
      gets `±Number.MAX_SAFE_INTEGER` as its width, so a `maximum` of
      `9223372036854775807` is clamped to `2^53 − 1` instead of generating ids
      that JavaScript cannot hold exactly. Tests: the compiled plan, and the
      independent validator over a generated body.
- [ ] **A bound outside the format's width is refused.** An `int32` whose
      `minimum` is `2^40` (or whose `maximum` is below `−2^31`) has no value at
      all; today the out-of-range bound survives clamping because the other
      side is absent, and the generator produces values above `2^31`. It is now
      refused as `unsatisfiable`, naming the format. The same check covers
      `int64` past the safe range.
- [ ] **A one-sided bound near the width's edge stays inside it.** With only a
      `minimum`, the generator draws from `minimum..minimum + 1000`; near the
      top of an `int32` or the safe range that window crosses the edge, so the
      maximum is filled with the width's bound in that case only.

## Follow-ups proposed, not built

- Serve integers > 2^53 losslessly (a lossless JSON parse/serialize path end to
  end). Today they are reported and their files refuse rewrites (#73).
- Install footprint (~92 MB: `effect` ~33 MB, `typescript` ~23 MB): check
  whether either can be lazy-loaded or optional.
