# The name

The name is made up of 2 Quechua words, llulla (which means false) and chasqui (which refers to a messenger), which together I give the meaning "false-messenger" (lLUlla + chasQuI = LUQI), since it's a server (messenger) that sends false information. Also, in English it sounds like the word "lucky"
